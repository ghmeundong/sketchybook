웹 게임 개발

[문서 상태 안내 - 2026-11 검토]
- 이 파일은 초기 기획 메모이며 현재 구현의 최종 사양이 아니다. 최신 동작은 README와 docs/DEVELOPER_GUIDE.md 및 관련 기능 문서를 기준으로 한다.
- 현재 18개 스테이지, 계정 기반 맵 메이커, Google 로그인, Cloudflare Worker 기반 협력 멀티플레이 프로토타입이 구현되어 있다.
- 난이도별 선 길이 제한은 Easy 무제한, Normal 5000px, Hard 2500px, Insane 1250px이다. 상세 규칙은 docs/DIFFICULTY_SYSTEM_BRIEFING.md를 참고한다.
- 백엔드는 D1 계정 데이터와 Durable Object 멀티플레이 룸을 사용한다. Supabase는 초기 제안이며 현재 구현이 아니다.

[게임 컨셉]
- 기본 구조: 공을 굴려 별을 먹는 퍼즐
- 플레이 방식: 사용자가 화면에 선(Line)을 그려서 공의 진행 경로를 유도

[난이도 시스템 (Difficulty Levels)]

## Easy
- 빨간 영역(Dead Zone): 삭제
- 바닥(Floor): 있음
- 공 위로 그리기: 가능
- 선 길이 제한: 무제한
- Challenge 모드: 비활성화

## Normal
- 빨간 영역(Dead Zone): 최소화 (라벨 추가하여 숨김처리)
- 바닥(Floor): 있음
- 공 위로 그리기: 가능
- 선 길이 제한: 5000px
- Challenge 모드: 비활성화

## Hard
- 빨간 영역(Dead Zone): 현재 맵 구조 따라감
- 바닥(Floor): 없음
- 공 위로 그리기: 금지 (현재 기능 유지)
- 선 길이 제한: 2500px
- Challenge 모드: 활성화 가능

## Insane
- 빨간 영역(Dead Zone): 최대화
- 바닥(Floor): 없음
- 공 위로 그리기: 금지
- 선 길이 제한: 1250px
- Challenge 모드: 강제 활성화

## UI/UX
- 난이도 선택: 메인 화면에서 <> 버튼으로 슬라이드 방식
- 선택된 난이도: 시각적으로 강조 표시

[플랫폼/배포]
- 프론트엔드: GitHub Pages로 정적 배포
- 백엔드:
  - 캐주얼 싱글플레이 → 불필요
- 서버리스 스토리지:
  - 현재 구현: Cloudflare D1 계정 데이터와 Durable Objects 멀티플레이 룸

[로그인/저장]
- 단순 점수 저장:
  - LocalStorage 기반
  - 같은 브라우저/기기에서만 유지
- 확장 기능 (초기 제안, 현재는 Google 로그인과 계정 기반 맵 저장 구현):
  - 당시 제안: OAuth 인증 후 유저별 데이터 공유
  - Supabase 연동은 현재 백엔드 구성에 포함되지 않음

[UI/연출]
- roughjs로 손그림풍 UI 구현
- 종이 질감 배경 이미지 활용
- 로그인 버튼:
  - 구글 로그인 버튼을 게임 UI에 맞게 커스텀

[물리 엔진]
- Planck.js:
  - 가볍고 브라우저 친화적 → 캐주얼 퍼즐에 최적
  - force 적용으로 바람/자석 효과 구현 가능
  - constraints로 쇠사슬, 스프링 구현 가능

[구현 목표]
- 선(Line) 처리:
  - 오브젝트와 겹칠 경우 → 합쳐져 고정
- 화면 비율:
  - 기본 기준은 16:9
  - 세로(height)를 기준으로 논리 좌표계 설정
  - 가로(width)는 여백 처리, 울트라와이드 모니터는 배경으로 채움
- 논리 좌표계:
  - 내부 좌표계를 고정 1600:900
  - 실제 화면 크기에 맞춰 scaleX, scaleY로 변환
  - 오브젝트 위치/크기는 논리 좌표계 기준으로 계산
- 모바일:
  - 강제로 가로 모드(90도 회전) 고정
  - 화면 비율 편차는 스케일링으로 대응

[향후 확장 아이디어]
- 스테이지 에디터: 구현됨 (맵 메이커, 계정 저장 및 JSON 내보내기)
- 글로벌 랭킹: 점수 경쟁 기능 추가
- 협력 플레이: 구현됨 (Cloudflare Durable Objects 기반 프로토타입; 동기화 복구는 추가 작업 필요)
